Before you start

Finding bndt in your DAW

  • Logic / GarageBand: Software Instrument → AU Instruments → Switchkicker → bndt
  • Ableton Live: Plug-Ins → VST3 → Switchkicker (turn on "Use VST3 Plug-In System Folders" in Settings → Plug-Ins if it doesn't show)
  • Other DAWs: rescan plug-ins after installing.

Using the vocoder

  1. Pick a preset from the Vocoder category, or switch the Vocoder section on.
  2. Send a vocal (or any track) to bndt's sidechain input. In Logic, choose it from the Side Chain menu at the top of the plug-in window. In Ableton, use the sidechain section of the device.
  3. Set INPUT so the meter lights mostly teal, then hold chords.

In the standalone app the vocoder listens to your audio input (Options → Audio/MIDI Settings). macOS will ask for microphone access the first time.

Your presets

Saved sounds go to ~/Documents/Switchkicker/bndt/Presets. Reinstalling or uninstalling never touches them.
